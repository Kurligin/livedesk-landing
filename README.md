# LiveDesk — лендинг

Статическая витрина платформы видеоконференций LiveDesk: главная страница
и юридические документы. Собирается в набор статических файлов и разворачивается
на любом хостинге статики (Timeweb Apps, Cloudflare Pages, Netlify).

Бэкенд платформы к этой сборке не подключён: регистрация, вход и присоединение
к встрече сообщают, что функция временно недоступна.

## Стек

React 18, Vite, React Router, marked + DOMPurify для рендера markdown-документов.

## Разработка

```bash
npm ci
npm run dev      # http://localhost:3000
npm run build    # сборка в dist/
npm run preview  # локальный просмотр собранной версии
npm run lint
```

## Структура

```
src/
├── pages/
│   ├── LandingPage.jsx   # главная: hero, возможности, тарифы, CTA
│   ├── LegalPage.jsx     # рендер markdown-документов + их список
│   └── NotFoundPage.jsx
├── components/
│   ├── Footer.jsx
│   └── CookieBanner.jsx
├── legal/                # тексты документов (markdown) и подстановка реквизитов
├── shared/ui/            # тосты, ErrorBoundary
├── router.jsx            # /, /legal, /terms, /privacy, /cookies, 404
└── styles.css
```

## Реквизиты в документах

Все реквизиты подставляются из `src/legal/config.js` по плейсхолдерам вида
`{{INN}}`. В этой публикации там условные значения — перед реальным запуском
их нужно заменить на настоящие.

## Деплой

Поведение статических хостингов на клиентских маршрутах различается, поэтому
сборка дублирует `index.html` сразу в нескольких видах: `404.html`,
`terms/index.html`, `terms.html` (и так же для остальных маршрутов), плюс файл
`_redirects`. Прямая ссылка на `/terms` открывается в любом из вариантов.

| Параметр           | Значение                  |
| ------------------ | ------------------------- |
| Команда сборки     | `npm ci && npm run build` |
| Каталог публикации | `dist`                    |
| Версия Node        | 20 или новее              |
