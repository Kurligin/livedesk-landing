# Юридические документы

Markdown-исходники страниц `/terms`, `/privacy` и `/cookies`.

Каждый файл импортируется с суффиксом Vite `?raw` в `src/pages/LegalPage.jsx`
и рендерится через `marked` с санитизацией DOMPurify.

Плейсхолдеры вида `{{INN}}` подставляются из `src/legal/config.js`. В этой
публикации там условные значения — перед реальным запуском их нужно заменить.

Файлы `personal_data_consent.md` и `recording_consent.md` на сайте не
отображаются: это тексты согласий, которые показываются внутри продукта.
